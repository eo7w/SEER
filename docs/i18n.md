# Internationalization

Script ships 11 locales under `locales/`, all key-parity-checked.

## File format

```json
{
  "meta": { "name": "العربية", "dir": "rtl" },
  "app":  { "name": "Script", "tagline": "…" },
  "nav":  { "chat": "…", "projects": "…", "usage": "…" },
  "chat": { "newChat": "…", "placeholder": "…", "greeting": "…" },
  "actions": { "send": "…", "copy": "…", "regenerate": "…" },
  "settings": { "title": "…", "theme": "…", "language": "…" }
}
```

- `meta.dir` — `rtl` flips the layout direction for that locale.
- Keys are stable identifiers; never rename a key without migrating all 11
  files.

## Parity rules

Every locale must contain **exactly the same key set** as `en.json`.
`npm run check:locales` and `tests/locales.test.js` both enforce this and
run in CI — a PR that updates `en.json` without the other 10 files fails.

## RTL support

The layout uses flex ordering and logical layout rules, so `dir="rtl"` on
the root mirrors the entire three-panel shell without per-component work.
The drawer, composer attachments strip, and nav all follow automatically.

## Adding a locale

1. Copy `en.json` to `xx.json` and translate every value.
2. Set the correct `meta.name` and `meta.dir`.
3. Run `npm run check:locales` — it will confirm parity.
